# Генератор экзаменационных билетов

Небольшое Windows-приложение на C# и WPF (.NET 9), которое генерирует номер экзаменационного билета и сохраняет данные студента в Excel-файл `journal.xlsx`.

## Запуск

```powershell
dotnet run --project LAB_OH.csproj
```

## Тесты

```powershell
dotnet test Tests/LAB_OH.Tests.csproj
```

Для открытия проекта в Visual Studio используйте файл `LAB_OH.sln`.
